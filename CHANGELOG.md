# v0.0.129
- (Development) Significant refactoring of packages
- (Development) Significant replacement of hard-coded strings with constants (involving most classes)
- (Development) Several large classes have been refactored into small ones for improved maintainability.
- Implemented the Viewer option to import overrides of earlier sessions (checkbox left bottom).



# v0.0.127

- TrackMate plugin supports a parameter sweep on Threshold (handy for the initial determination for optimal threshold values for new a experiment).
- Misformed JSON files are recognised and handled gracefully. 
- (Development) Several large classes have been refactored into small ones for improved maintainability.



# v0.0.122

- New installer for Windows and macOS allows installation of individual components. The location of the  Fiji installation, if not found, can be specified by the user (and the choice is remembered for later installations). 

- The Viewer has a new 'Show Squares' option to show the data of all squares
