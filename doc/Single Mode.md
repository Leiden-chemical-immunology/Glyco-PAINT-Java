# Single Mode



In addition to the original 'Run' mode, a new 'Run Single' mode has been added (The original 'Run' mode has been renamed to 'Run Batch').

Run Single starts as Run Batch, but now you can choose only a single experiment (checkboxes have been replaced by radio buttons).

<img src="./Pictures/single-mode-experiment.png" alt="single-mode-experiment" style="zoom: 33%;" />

When you click OK, a new dialog comes up, showing the recordings in the experiment. Again, you can select only one recording (radio buttons).

<img src="./Pictures/single-mode-recording.png" alt="single-mode-recording" style="zoom:33%;" />

For that recording, the current Threshold value is retrieved from the Experiment Info file. A slider allows you to change that Threshold value. By pressing 'Calculate' you start TrackMate. You can run multiple timed with different values. If you have found a better Threshold value than the one in the Experiment Info file, you can save that value, for that recording, by pressing 'Save'.
